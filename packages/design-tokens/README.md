# `design-tokens`

Shared design primitives for web/admin and reference parity with mobile.

## Tokens
- Typography scale.
- Spacing.
- Radius/elevation.
- Semantic colors.
- Tide/water states.
- Drainage status states.
- Confidence states.
- Chart tokens.
- Breakpoints.

The mobile app may use generated/translated token definitions appropriate to Flutter rather than importing TypeScript directly.

All critical status tokens must include non-color semantics in components (icon/text), not only color.
