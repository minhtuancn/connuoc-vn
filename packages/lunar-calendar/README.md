# `lunar-calendar`

Pure Vietnamese lunar-calendar domain package.

## Owns
- Gregorian ↔ lunar conversion.
- Leap-month rules.
- Can Chi and solar-term interfaces.
- Vietnamese-calendar date types.

## Rules
- Vietnam timezone assumptions must be explicit.
- Supported date range must be documented/tested.
- No UI/network/database dependency.

See `docs/LUNAR-CALENDAR.md`.
