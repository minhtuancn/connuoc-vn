# `tide-engine`

Pure deterministic tide-prediction domain package.

## Owns
- Harmonic constituent types/calculation.
- Tide series generation.
- High/low extrema detection.
- Rising/falling/stand state.
- Prediction metadata/version.

## Must not own
- Network fetching.
- Database persistence.
- River flood prediction.
- UI formatting.
- AI-generated values.

See `docs/TIDE-ENGINE.md`.
