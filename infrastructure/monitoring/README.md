# Monitoring

Observability configuration and dashboards belong here.

Baseline signals:
- API availability/latency.
- Source freshness.
- Import/parser failures.
- Forecast generation duration/errors.
- Queue depth/failed jobs.
- Database capacity.
- Notification failures.
- Mobile/web error and crash health.

Preferred standards: OpenTelemetry, Prometheus and Grafana-compatible metrics/dashboards.
